# Ryan Olson

**Founder and engineer. I build communities for adults, and the money that moves through them.**

I've been building and running social platforms since 2010. The first one was Fetishmen, which grew into Real Kink Men. Today it runs on a platform I designed to host many communities at once, with native apps, live video and its own billing, built and run end to end from Toronto.

---

### What I'm building

**[Real Adult Media](https://www.realadult.media)** — *Communities for adults.*
Social networks where each community is its own place, with its own people, its own rules and its own name. They all run on **narwhal**, one platform built to carry many brands.

### Under the hood

| | |
|---|---|
| **Platform** | Laravel and PHP 8.4, Inertia with React and TypeScript, Tailwind. Profiles, circles, events, messaging, a journal and a full moderation desk, in seven languages. |
| **Apps** | Expo and React Native on iPhone, iPad and Android. Native push, CallKit calling, over-the-air updates. |
| **Real time** | Live video rooms, one-to-one calls inside messages, and On Air broadcasting from a phone. WebRTC, Agora and Laravel Reverb. |
| **Media** | An FFmpeg pipeline in Docker for every photo and video members upload. |
| **Billing** | A recurring billing engine we run ourselves, with the card processor only processing. |
| **Infrastructure** | DigitalOcean, Docker, MySQL, Valkey, Horizon queues, Nightwatch monitoring. |

### Open source

- [**photo-metadata**](https://github.com/realadultmedia/photo-metadata) — strips location, camera and owner data from JPEG, PNG and WebP photos in PHP, without re-encoding them.
- [**expo-face-boxes**](https://github.com/realadultmedia/expo-face-boxes) — finds faces on the device with Apple Vision and ML Kit, so they can be covered before a photo is shared.
